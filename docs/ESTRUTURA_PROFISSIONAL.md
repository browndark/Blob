## 📋 Comandos Principais

### 🚀 **Execução**
```bash
# Execução rápida
./scripts/run.ps1

# Execução manual
python blob_corrigido.py
```

### 🧪 **Testes**
```bash
# Teste das correções
python tools/testing/teste_correcoes_direto.py

# Testes de debug
python tools/testing/teste_debug_cumprimento.py
```

### 🛠️ **Manutenção**
```bash
# Limpeza completa
python tools/database/limpeza_completa.py

# Verificar nomes
python tools/database/verificar_nomes.py

# Forçar nome BLOB
python tools/maintenance/force_blob_name.py
```

### 🔨 **Build**
```bash
# Build completo
./scripts/build.ps1

# Instalação como pacote
pip install -e .
```
